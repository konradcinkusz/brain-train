%  arrangement: a chapter cannot go missing from one format, because there is
%  only one list of chapters.
%
%  Build:  make book        -- from the repository root, gated on the log
%          latexmk -pdf main-pl-a4.tex   -- from this directory, ungated
%
%  Do NOT trust latexmk's exit code alone. Under -interaction=nonstopmode a
%  failed run still writes a PDF, and with -file-line-error an error line
%  begins with a path rather than "!", so `grep '^!'` sees nothing either.
%  tools/checklog.py is the gate.
% ============================================================
